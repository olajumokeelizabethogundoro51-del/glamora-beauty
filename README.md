# Glamora Beauty

Glamora Beauty is a responsive beauty website I created to showcase makeup products and make it easy for visitors to explore beauty items.

### Built With
 HTML
 CSS
 JavaScript

### Features
 Responsive design
 Product display and shopping cart
 Beauty products from a public API
 Search and filter
 Contact form validation
 Dark mode and light mode

### What I Learned
